TwinsRemoteはゲーム好きのための低遅延P2Pリモートプレイシステムです。

TwinsRemoteは<b>配信元である「ホスト」</b>と<b>配信先である「クライアント」</b>にユーザーが分かれます。

ホスト・クライアントの動作環境は[こちら](#必要環境)を参照ください。

# 特徴

## 低遅延配信

* WebRTC を利用したP2P通信
* 安定した回線環境では数十ms程度の低遅延
* ゲームプレイを前提とした設計

---

# 必要環境

## ホスト側

* Windows OS (Windows 11である必要はないです)
* NVENC対応 NVIDIA GPU
  * NVIDIA公式の対応表は[こちら](https://developer.nvidia.com/video-encode-decode-support-matrix)を参照ください
    * <b>公式の対応表に書かれていなくても動作するGPUがある</b>ので、まずは動作確認をすることをお勧めします

<b>注:ノートPCを使っている場合、内臓ディスプレイが原因でTwinsRemoteの動作に支障が出ることがあります</b>

<b>詳しくは[こちら](#映像がカクカクしてたり遅れたりする)</b>

# FAQ

### Steam専用ですか？

いいえ。

TwinsRemote は Steam に依存していません。

以下のような用途にも利用できます。

* Steam以外のゲーム
* エミュレーター
* デスクトップアプリ

---

### クライアント側にインストールは必要ですか？

不要です。

ブラウザのみで利用できます。

---

### なぜ ViGEm が必要なのですか？

[ViGEm](https://vigembusdriver.com/download/) を利用してホスト側に仮想コントローラーを生成し、ゲーム側へクライアント入力を渡しているためです。

---

### クライアントのコントローラー入力が効きません

クライアント側のログに「gamepad connected: ~」と出ている場合はコントローラーは認識されています

それでも入力が効かない場合は以下を確認してください。
* クライアントPCのフォーカスが TwinsRemote Client のタブになっているか
  * クライアントPCで直前に別ウィンドウや別のアプリを操作しませんでしたか？
* ホストPCのフォーカスが起動しているゲームになっているか
  * ホストPCで直前に別ウィンドウや別アプリを操作しませんでしたか？
  * 開発者は「アプリ音声」の共有をした後、ゲームウィンドウをクリックしてないというミスを何回もしました
* ゲームの対応コントローラーをチェックしてください
  * 「XBoxコントローラーのみ対応」など、ゲームによって対応しているコントローラーが違う可能性があります
* 一度ホストとクライアントの接続を切ってつなぎなおしてください
  * それでも認識されなかった場合は開発者に報告してください

---

### 映像がカクカクしてたり遅れたりする

* 配信モードを高い設定にしていませんか？
  * <b>マンションの共有回線</b>を使いながら<b>「4K」</b>で配信するなどインターネット回線が配信モードの設定に追い付いていない可能性があります
* ノートPCの内蔵ディスプレイの映像を共有していませんか？
  * ノートPCの内蔵ディスプレイはハードウェア制約によりTwinsRemoteの性能を発揮するのが難しいです
  * 外部ディスプレイにつないでその映像を共有することで解消されます

# プロジェクトについて

このプロジェクトは、開発者と双子の兄が遠隔でゲームを遊ぶために作り始めたシステムです。

「Twins Remote」という名前には:

* 開発者が双子の兄と遊ぶために始まったプロジェクトであること
* 離れたPC同士を双子のように近い存在にしたいこと

という意味を込めています。
